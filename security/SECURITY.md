## Reporting a vulnerability

If you discover a security vulnerability in Veil Messenger, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Contact: security@veil.example (update before production)

We aim to respond within 72 hours.

## Scope

- Veil Messenger mobile apps (iOS, Android)
- veil-relay server
- Cryptographic implementations

## Safe harbor

We support good-faith security research on released versions.
